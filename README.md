# 🌸 Daily Bloom

Daily Bloom is a personal productivity application designed to help users organize daily tasks, build consistent habits, and track their progress.

## ✨ Features
- Daily task and productivity management
- Installable Progressive Web App (PWA)
- Mobile-friendly experience
- Android project support through Capacitor

## 🛠️ Tech Stack
- Next.js
- TypeScript
- CSS
- Capacitor

## 🚀 Live Demo
[Try Daily Bloom](https://daily-bloom-pi.vercel.app)

## 💻 Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/choureanjali/daily-bloom.git
   ```
2. Navigate into the project folder:
   ```bash
   cd daily-bloom
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```

Open `http://localhost:3000` in your browser.
